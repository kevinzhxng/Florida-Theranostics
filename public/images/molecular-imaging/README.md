# Molecular Imaging Page – Image Filenames

Add your modality images to this folder. The page expects these filenames:

**PET-CT Imaging**
- `amyloid-pet.jpg` – Amyloid PET Brain
- `psma-pet.jpg` – PSMA PET-CT (prostate cancer)
- `fdg-pet.jpg` – F-18 FDG
- `dotatate-pet.jpg` – DOTATATE PET
- `fes-pet.jpg` – FES-PET Cerianna™
- `flurpiridaz-pet.jpg` – F-18 Flurpiridaz FLYRCARDO™

**SPECT-CT Imaging**
- `datscan.jpg` – DATscan (Parkinson's)
- `thyroid-scan.jpg` – Thyroid scan and uptake
- `parathyroid-sestamibi.jpg` – Parathyroid Sestamibi SPECT-CT

You can use `.webp` instead of `.jpg`; if you do, update the paths in `app/molecular-imaging/page.tsx` (e.g. `amyloid-pet.webp`).
